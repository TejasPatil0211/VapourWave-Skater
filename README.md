VAPOURWAVE SKATER 

Yo guys I am making a endless skating game inside shaders.Where the main objective is to dodge obstacles and collect coins. 

This game is a submission for the wrong tool hackclub challange.

The original idea was about making a spaceship racing game but I couldn't fix the orientation of the space ship and the collision with ai bugged and it kept teleporing ahead so it made the game unfair thus, I changed my idea to a endless skating game.

I have made this game with the following features:

1. Endless Skating game with procedurally generated obstacles.
2. Ability to perform tricks on rails like kick flips, ollie, grind, etc.
3. The game is made completely inside shaders so please expect some bugs like wierd orientation and stuff.

I have added the following characters:

1. A Skinny Skater (Inspired by a flash style android game called skater boy)

Instructions for playing:

1. `A/D` to switch lanes.
2. `W` to jump over obstacles.
3. `S` to slide under obstacles.
4. There are two types of obstacles: A. The Jumpable Barricade(Orange) and B. Slideable obstacles(Purple).
5. You can't slide through orange ones and you can't jump over the purple ones. 

I believe that the bugs found might be the result of the usage of shaders which causes bugs while trying to replicate 3D. 

Sorry for any and all bugs related to my code and shader engine.
